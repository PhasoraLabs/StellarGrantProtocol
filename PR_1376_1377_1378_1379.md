## Changes

### #1376 — emit event on whitelist add and remove
`whitelist::add` / `whitelist::remove` already publish `WhitelistAddressAdded` / `WhitelistAddressRemoved` (defined in `events.rs`, carrying the affected address and scope). They had no direct test coverage, so I added tests that assert the exact event payload for add and remove. They also assert that nothing is emitted for a no-op remove or a rejected (unauthorized) add.

### #1377 — tests for multisig threshold changes while proposals are pending
- Documented the intended semantics at the top of `multisig.rs`: the threshold is snapshotted on the proposal at creation and is the only value `sign`, `execute` and `is_threshold_met` read.
- Added tests for the following cases:
  - Later proposals with a different threshold don't affect a pending one.
  - Lowering a pending proposal's threshold unlocks execution.
  - Raising it blocks execution, and collected signatures are kept.
  - An already-executed proposal stays executed.

### #1378 — max length validation for grant tags
- Added `MAX_TAG_LENGTH = 32`, alongside the existing `MAX_FREEFORM_TAGS = 10`, in `grant_tags.rs`.
- Added typed errors `ContractError::TagTooLong` (152) and `ContractError::TooManyTags` (153) in `errors.rs`. Previously an oversized tag list returned the generic `InvalidInput`.
- The shared `validate_freeform_tags` check is applied in both `tag_grant` and `update_tags`.
- Tests cover accepted values at the limits, an over-long tag, too many tags, and `update_tags` leaving the stored tags untouched after a rejected update.

### #1379 — tests for token_swap slippage protection
`swap()` and `quote()` are still stubbed (no DEX integration) and always revert with `SwapNotImplemented`, so the swap itself is not reachable. The new tests lock in that a swap whose `min_out` cannot be met reverts and leaves balances untouched. They cover:
- `min_out = i128::MAX`
- zero slippage tolerance
- an inactive DEX
- a negative amount

Real adverse-price-movement tests will need a mock DEX, which belongs with the actual DEX integration. No production swap logic was changed.
