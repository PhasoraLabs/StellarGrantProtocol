# test: coverage for badge, reputation_decay, milestone_template (#973, #974, #975)

## Summary

Adds `#[cfg(test)] mod tests` to three contract modules that previously had **zero**
test coverage. 22 new tests.

Closes #973
Closes #974
Closes #975

> **Note on #972 (grant_timer):** already covered on `main` by commit `2b13ca52`
> ("test: add coverage for grant timer registration and triggering"), so it is
> dropped from this PR — `main`'s `grant_timer.rs` test module is kept as-is.

## Changes Made

### `badge.rs` — 7 tests (#973)
- Award through `try_award` — the exact hook the milestone-approval payout path calls
  (`lib.rs`) — with a contributor profile that meets criteria; `has_badge` / `get_badges`
  / `award_count` all reflect it.
- A `one_time` badge is **not** re-awarded on a second qualifying milestone on a different grant.
- Criteria-not-met and unregistered-contributor both deny the award.
- Reputation-threshold gate (`BronzeContributor`) checked at 99 vs 100.
- `get_criteria` mapping; `manual_award` is admin-gated.

### `reputation_decay.rs` — 9 tests (#974)
- `exponential_decay` at shifts exactly **31 / 32 / 33** — the `shifts >= 32` shift-overflow guard.
- `exponential_decay` floor clamp after shifting to 0; zero half-life / zero-inactivity passthrough.
- `linear_decay` driven below `config.decay_floor` clamps to the floor.
- `apply_decay`: `enabled = false` passthrough, below-`inactivity_threshold_ledgers` passthrough,
  and correct routing to `None` / `Linear` / `Exponential`.
- `days_inactive` / `ledgers_inactive` return 0 when `now <= last_action_at`.
- `effective_score` reads profile fields; `record_activity` updates `last_action_at` and
  is a no-op for an unknown contributor.

### `milestone_template.rs` — 6 tests (#975)
- `save_template` → `create_from_templates` round-trip produces the expected
  `(description, amount)` pairs and bumps `use_count`.
- `delete_template` by a non-owner is rejected; a deleted template can no longer be used
  by `create_from_templates`; a used template (`use_count > 0`) cannot be deleted.
- Private template usable only by its owner; `public_templates` / `templates_by_owner`
  filter visibility correctly.

## Testing

The 22 tests were written and verified green (34/34 including the now-dropped grant_timer
set) against the pre-merge base. They follow the repo's established test pattern
(`checklist.rs`, `grant_pause.rs`): register the contract once, then run each
`require_auth`-bearing call in its own `env.as_contract(&id, …)` frame.

> ⚠️ **`main` does not currently compile.** `cargo check --workspace --target
> wasm32v1-none` fails on `main` with ~34 errors unrelated to this PR — missing
> `ContractError` variants (`DaoVoteRequired`, `SwapNotImplemented`,
> `TooManyPublicReviews`, `InsufficientClawbackAllowance`) still referenced by
> `params.rs` / `token_swap.rs` / `open_review.rs` / `clawback.rs`, plus stale SDK
> API use (`Vec::as_slice`, `Vec<u8>::push_back`, `Env::invoker`). Because CI now runs
> `cargo test --workspace`, **every open PR has red CI until `main` is fixed.** This
> PR adds only test code and does not contribute to that breakage; the new tests can
> be run once `main` compiles again.
